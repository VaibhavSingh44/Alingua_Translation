# Alingua_Translation
A real-time Language Translation web application built with Streamlit and powered by the Google Gemini API.
• Contextual Translation: Powered by the Gemini API to understand idioms, tone, and context, rather than doing simple word-for-word translation.
• Multi-Language Support: Seamless translation across dozens of international and regional languages.
• Intuitive UI: A clean, responsive dashboard built completely in Python using Streamlit for an effortless user experience.
• Secure API Management: Dynamic key handling to ensure safe interactions with Google AI services.
